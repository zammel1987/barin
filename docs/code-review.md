## 修复计划

所有 ✅ 和 ⏳ 的问题都会在开 PR 前修复，K、L、N 也一并顺手处理。修复要点：

- **A**：成年螳螂不提供「标记为蜕皮前期」；如果已经处于前期，一律显示结束按钮。
- **B**：默认日期改用本地日期。
- **C**：入手日期设为必填，逻辑上也做兜底。
- **D、E**：适应期只看入手日期之后有没有进食成功的记录，拒食不结束适应期。
- **F**：吐食也算开过食。
- **G**：先保存蜕皮记录，再清除前期状态。
- **H**：撤销时只恢复 `premoltSince` 这一个字段，不整份写回宠物资料。
- **I**：用「覆盖」方式导入时，只认备份文件里的宠物。
- **J**：改用 `Object.hasOwn` 判断。
- **K**：按钮加防连点。
- **L**：`addDays` 改为按日期计算。
- **M**：归档区不再放在表单里提交。
- **N**：下载链接 60 秒后才失效。
