# 爬宠饲养记录

一个用于记录螳螂、蜘蛛、蛇饲养情况的 PWA 应用。数据保存在本地，可以离线使用。

## 功能
- 宠物管理：种类、品种、性别、入手日期；按幼体 / 亚成 / 成体分别设置喂食间隔（有物种默认值）
- 首页卡片显示距上次喂食/排便天数和**下次喂食日**，可按「待办优先 / 临近蜕皮 / 名字」排序
- **喂食到期引擎**：以下时期不提醒「该喂了」，卡片显示原因和天数
  - 蜕皮前期 / 蓝眼期（手动标记，或在连续拒食提醒上一键标记；记录蜕皮后自动结束）
  - 蜕皮后硬化期（螳螂 1–2 天、蜘蛛 5–12 天，按阶段默认，可改）
  - 蛇吐食后休整期（14 天，30 天内再次吐食为 21 天）
  - 到家适应期（螳螂 1 天、蜘蛛 3 天、蛇 7 天，可改）
- 分级提醒（信息 / 注意 / 危险）：连续拒食、剩饵未取出、蛇消化期勿上手、反复吐食、到家未开食、进食后未排便、排便异常、临近蜕皮等
- 详细记录：喂食（食物/数量/已吃·拒食·吃剩·吐食，剩饵提醒）、排便、加水/换水、喷雾、蜕皮（龄期/是否完整）、体重、清洁、备注；均可附照片
- **加水/喷雾提醒**：每只可设间隔（0 为关闭），默认螳螂每 2 天喷雾、蜘蛛和蛇每 7 天加水；只做信息提示，可一键记录；卡皮时显示蜕皮前 7 天的喷雾和加水次数
- 录入减负：沿用上次食物、最近食物快捷按钮、今天/昨天/前天、保存后 5 秒内可撤销
- **批量记录**：一次记录多只的喂食、加水、喷雾或清洁；喂食按 已逾期 / 今天 / 明天 / 7 天内 / 暂停中 分组
- **蜕皮历史**：每次蜕皮的龄期、间隔、前期天数、是否完整，以及下次蜕皮预测窗口
- 年龄、龄期、成长阶段：出生日期精确计算，或按入手时蜕皮次数/月龄估算
- 日历视图、蛇体重折线图
- **归档**：死亡或转让的宠物可归档，保留全部记录，不再提醒，可恢复
- **导出 Excel / CSV**：宠物和全部记录两张表，也可单独导出一只宠物的记录（方便转让时交给买家）
- 数据安全：申请持久化存储；超过 14 天未备份时提醒；导入前预览，覆盖前自动下载当前数据快照

功能来源于对各大论坛饲主常见问题的调研，见 [docs/keeper-problems.md](docs/keeper-problems.md)。

## 开发
```bash
npm install
npm run dev     # 开发
npm test        # 单元测试（喂食到期、提醒、蜕皮预测等规则）
npm run build   # 构建到 dist/，可部署到任意静态托管（GitHub Pages、Vercel 等）
```
