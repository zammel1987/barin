# 爬宠饲养记录

一个用于记录螳螂、蜘蛛、蛇饲养情况的 PWA 应用。数据保存在本地，可以离线使用。

## 功能
- 宠物管理：种类、品种、性别、入手日期、喂食间隔（按物种预设默认值）
- 首页可一键记录 **喂食 / 排便**，并显示距上次的天数，超过喂食间隔时标红提醒
- 详细记录：喂食（食物/数量/已吃·拒食·吃剩）、排便（正常/异常）、蜕皮（龄期/是否完整）、体重、换水清洁、备注
- 智能提示：连续拒食可能进入蜕皮前期；蛇进食后 14 天未排便；排便异常
- 蛇体重折线图
- 日历视图：按月查看每天的记录，可按宠物筛选
- 记录可附照片（自动压缩），时间线中点击可放大
- 年龄：填写出生日期则精确计算；否则螳螂/蜘蛛按「入手时蜕皮次数 × 平均蜕皮间隔 + 已养天数」估算
- 节肢类自动计算龄期（L1 为孵化），并按成体龄期显示 幼体 / 亚成 / 成体，也可手动指定
- JSON 备份导出与导入（覆盖或合并）

## 开发
```bash
npm install
npm run dev     # 开发
npm run build   # 构建到 dist/，可部署到任意静态托管（GitHub Pages、Vercel 等）
```
